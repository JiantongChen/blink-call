# 遇到问题

遇到问题时，先观察主界面的画面和文字提示，再选择对应的排查方法。

## 先完成这几个检查

1. 确认软件已经完整解压，不是在压缩包内运行。
2. 确认模型文件已经下载完成。
3. 确认摄像头画面连续、清楚，患者面部和双眼完整可见。
4. 确认“设置 → 眨眼呼叫 → 开启眨眼呼叫”处于开启状态。
5. 确认电脑或蓝牙音箱没有静音。

如果问题仍然存在，请继续查看下面对应的情况。

## 软件无法打开 {#app-wont-open}

请依次检查：

1. 确认已经将下载的软件压缩包完整解压。
2. 进入解压后的文件夹，双击 `BlinkCall.exe`。
3. 不要移动或单独复制 `BlinkCall.exe`，它需要和文件夹中的其他文件放在一起。
4. 重新下载软件压缩包并解压到一个新的文件夹，再次尝试。

仍然无法打开时，请记录 Windows 版本、软件版本和屏幕上的提示，然后通过[GitHub Issues](https://github.com/JouleEmbodiedAILab/blink-call/issues)反馈。

## 模型文件下载失败 {#model-download-failed}

如果页面显示“网络连接超时”“网络连接失败”“请求模型信息失败”或“下载模型文件失败”：

1. 确认电脑能够正常访问网络。
2. 关闭下载提示后，重新进入“设置 → 眨眼呼叫”。
3. 再次点击“下载/更新”。
4. 等待整个进度完成，不要在下载过程中关闭软件。

下载成功后，进度窗口会关闭，设置会自动保存。主界面不再显示“未检测到模型文件”的提示。

如果多次尝试仍然失败，请记录页面显示的完整错误文字，并通过[GitHub Issues](https://github.com/JouleEmbodiedAILab/blink-call/issues)反馈。

## 摄像头没有画面 {#camera-no-image}

如果主界面显示“摄像头不可用”：

1. 确认摄像头已经正确连接。
2. 检查 Windows 是否允许桌面应用访问摄像头。
3. 关闭可能正在占用摄像头的会议、直播或拍照软件。
4. 打开“设置 → 摄像头”，选择“本地摄像头”。
5. 从编号 `0` 开始尝试；没有画面时依次尝试 `1`、`2`、`3`。
6. 每次修改编号后点击“保存”，回到主界面检查。

如果主界面显示“摄像头连接中断，正在尝试恢复”，请检查连接线并重新插入摄像头，然后等待软件自动恢复。

使用笔记本内置摄像头和外接摄像头时，可以设置备用摄像头。详细说明请查看[摄像头设置](camera.md)。

## 检测不到患者面部或双眼 {#face-eyes-not-detected}

主界面可能显示：

- “未检测到人脸”
- “人脸关键点定位失败”
- “关键点无效，请检查患者姿态或眼部遮挡”

请调整摄像头或患者位置：

1. 让患者面向摄像头。
2. 确保完整面部和双眼都在画面中，不要靠近画面边缘。
3. 移开遮挡双眼的头发、被子、手或眼镜边框。
4. 改善面部光线，避免面部过暗或强烈背光。
5. 保持患者和摄像头位置稳定，等待画面恢复识别。

## 眨眼进度不动或反复重新开始 {#blink-progress}

请检查：

1. “设置 → 眨眼呼叫 → 开启眨眼呼叫”是否为“开启”。
2. “显示首页上方进度条”是否为“显示”。
3. 患者面部和双眼是否能够被持续识别。
4. 每个睁眼或闭眼动作是否保持到当前阶段完成。
5. 完成一个阶段后，是否在 3 秒内开始了下一个阶段。
6. 当前实际动作是否与“设置 → 眨眼呼叫 → 眨眼序列”一致。

建议先恢复默认设置并测试默认序列。默认序列为：

**睁眼 1.5 秒 → 闭眼 1 秒 → 睁眼 1 秒 → 闭眼 1 秒**

如果患者难以完成当前动作，请查看[眨眼动作设置](blink-pattern.md)。

## 完成序列但没有触发呼叫 {#call-not-triggered}

1. 确认整个序列都已完成，进度没有在中途清零。
2. 确认“开启眨眼呼叫”处于开启状态。
3. 确认模型文件没有缺失或损坏；可以在“下载/更新模型文件”处重新检查。
4. 点击“保存”后返回主界面，再完成一次测试。

如果主界面显示“推理异常”或“眨眼功能异常”，请先关闭并重新打开软件。问题持续出现时，请记录提示文字并提交问题。

## 经常在无意中触发呼叫 {#false-trigger}

- 不要只使用很短的闭眼动作，以免与自然眨眼混淆。
- 适当延长闭眼持续时间。
- 增加一到两个动作步骤，让完整序列更容易与自然眨眼区分。
- 每次只修改一项，然后连续测试几次。
- 调整时兼顾患者体力，不要把序列设置得过长。

具体设置方法请查看[眨眼动作设置](blink-pattern.md)。

## 听不到提醒声音 {#no-sound}

1. 打开“设置 → 眨眼呼叫”。
2. 确认“播放呼叫音频”为“开启”。
3. 选择一个呼叫音频文件并点击“试听”。
4. 调高软件中的“音频音量”。
5. 检查 Windows 系统音量以及扬声器或蓝牙音箱音量。
6. 使用蓝牙音箱时，确认电脑仍然连接到正确的播放设备。
7. 保存设置并重新完成一次测试呼叫。

如果“试听”有声音，但触发呼叫后没有声音，请确认呼叫序列是否真的完成，以及呼叫提醒界面是否出现。

## 设置被改乱 {#reset-settings}

进入“设置 → 其他 → 恢复默认设置”，确认恢复后重新完成一次测试呼叫。

恢复默认设置会重置眨眼动作、摄像头、声音和界面等配置，不会删除已经下载的模型文件。

## 提交问题时请提供 {#report-issue}

通过[GitHub Issues](https://github.com/JouleEmbodiedAILab/blink-call/issues)反馈时，建议提供：

- 眨眼呼叫版本号。
- Windows 版本。
- 问题发生前执行了哪些操作。
- 预期看到什么，以及实际看到了什么。
- 主界面显示的完整提示文字。
- 能够帮助说明问题的截图。

如果工作人员需要日志或摄像头录制，会进一步说明如何获取。摄像头录制可能包含患者面部和周围环境，请先征得同意，不要在公开问题中直接上传敏感画面。
