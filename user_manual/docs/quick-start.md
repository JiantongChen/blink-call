# 快速开始

这一部分帮助家属或照护者完成第一次配置，并掌握日常呼叫方法。

## 第一次使用流程

1. **下载并解压软件**：将软件放在一个固定位置。
2. **打开软件**：双击 `BlinkCall.exe`。
3. **下载模型文件**：进入“设置 → 眨眼呼叫 → 下载/更新模型文件”。
4. **确认摄像头画面**：允许摄像头权限，让患者的双眼完整出现在画面中。
5. **完成测试呼叫**：按照顶部进度条完成默认眨眼序列，确认提醒声音正常。

完整步骤、截图和成功标志请查看[首次使用](first-use.md)。

## 日常使用流程

1. 打开软件。
2. 确认摄像头画面连续、清楚。
3. 确认患者双眼没有被遮挡。
4. 按当前设置完成眨眼序列。
5. 如需提前结束铃声，由照护者点击呼叫提醒界面。

详细说明请查看[日常使用](daily-use.md)。

## 如果中途遇到问题

- 软件无法打开或模型文件下载失败。
- 摄像头没有画面，或者画面中检测不到人脸。
- 眨眼进度不动、无法触发或经常误触发。
- 呼叫已经触发，但听不到提醒声音。

遇到以上情况，请进入[遇到问题](troubleshooting.md)。

## 配置完成的标准

完成首次配置后，应同时满足以下条件：

- 主界面能够连续显示患者画面。
- 顶部进度条能够跟随睁眼、闭眼动作变化。
- 患者可以在不过度疲劳的情况下完成眨眼序列。
- 完成序列后，照护者能够听到提醒声音。
- 照护者能够停止提醒，并知道在哪里调整动作、摄像头和声音。
