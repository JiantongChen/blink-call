# 快速开始

## 首次使用
1. 点击左上角【设置】按钮打开设置窗口。
2. 在【眨眼呼叫】-【下载/更新模型文件】处，点击【下载/更新】按钮，等待模型文件下载完毕。

## 开始呼叫
1. 保持面部在画面中，面部区域大小适中。最重要的是要能清晰看清双眼的睁闭状态。
2. 按已设置的眨眼序列执行动作。可使用上方进度条辅助观察：
   - 浅绿色代表睁眼
   - 浅黄色代表闭眼
   - 深绿色代表当前眨眼进度
3. **重要**：在眨眼序列中，请保持睁/闭眼直至当前阶段完成。在完成后的 3 秒内开始做下一阶段的睁/闭动作，否则眨眼进度会清零。
4. 触发后进入呼叫提醒状态，电脑会在设定的时间内播放声音提醒。如需提前关闭，请点击软件下方的关闭按钮。
