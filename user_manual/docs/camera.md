# 摄像头设置

摄像头设置用于选择当前使用的摄像头，并帮助软件稳定看到病人的双眼。

## 本地摄像头

本地摄像头是指连接在当前电脑上的摄像头，例如电脑内置摄像头或 USB 摄像头。

默认情况下，软件会使用本地摄像头。

## 选择摄像头编号

如果电脑连接了多个摄像头，可以在设置中调整摄像头编号。

操作路径：

设置 -> 摄像头 -> 本地摄像头 -> 摄像头编号。

建议：

- 先从编号 0 开始尝试。
- 如果画面没有显示，可以依次尝试 1、2、3。
- 每次修改后保存设置，并回到主界面查看画面是否正常。

![选择摄像头](images/camera-settings.png)

## 画面要求

病人的双眼需要完整出现在画面中，眼睛不要被遮挡。

建议避免：

- 眼睛离画面边缘太近。
- 眼睛被头发、被子、手、眼镜边框遮挡。
