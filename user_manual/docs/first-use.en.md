# First Use

This page is for family members or caregivers who are setting up the software for a patient for the first time. Please complete the steps in order.

## Download and Extract the Software

Download the latest software package from one of the download links, then extract it to a fixed location.

Do not run the software directly inside the compressed package. Extract it first, then open it.

![zip](images/zip.png)

## Open the Software

Open the extracted software folder and double-click `BlinkCall.exe`.

![app](images/app.png)

## Download or Update Model Files

Model files must be downloaded before the first use.

Path:

Settings -> Blink Call -> Download/Update Model Files.

Click [Download/Update] and wait for the download to finish. After it finishes, save the settings and return to the main screen.

![Download model files](images/quick-start-download-model.gif)

## Allow Camera Access

If the system asks for camera permission, allow the software to access the camera.

If no permission window appears, continue to the next step.

![authority](images/authority.png)

## Select the Camera

By default, the software uses the local camera.

If the computer has multiple cameras connected, you can adjust the camera number in Settings.

![Select camera](images/camera-settings.png)

## Adjust the Patient and Camera Position

Both eyes should appear fully in the camera view, and the eyes should not be covered.

## Complete One Test Call

Use the default blink sequence for testing:

Eyes open for 2 seconds -> eyes closed for 2 seconds -> eyes open for 2 seconds -> eyes closed for 2 seconds.

After the call is triggered, the software will play an alert sound. After confirming that the sound works, click the stop button to end the alert.

![Blink call](images/quick-start-call-alert.gif)
