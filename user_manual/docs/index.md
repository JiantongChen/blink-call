# 眨眼呼叫 用户手册

**眨眼呼叫** 是一个为 ALS（肌萎缩侧索硬化，俗称渐冻症）患者设计的辅助呼叫系统。软件通过摄像头识别预设的睁眼、闭眼动作，在完成眨眼序列后播放呼叫提醒声音，帮助病人在需要时向家属或照护者发出提醒。


## 适合谁使用

- 说话困难，无法方便地发出呼叫声音。
- 手部操作困难，无法稳定点击按钮或使用实体呼叫器。
- 可以通过睁眼、闭眼完成简单动作。
- 有家属或照护者协助完成首次配置。

## 使用前准备

- 一台 Windows 电脑。
- 可用摄像头。
- 网络连接，首次下载模型文件时需要。
- 电脑扬声器或蓝牙音箱。
