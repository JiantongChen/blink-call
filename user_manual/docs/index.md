# 眨眼呼叫 用户手册

**眨眼呼叫** 是一个为 ALS（肌萎缩侧索硬化，俗称渐冻症）患者设计的辅助呼叫系统。它可以从摄像头输入中识别用户自定义的眨眼模式，并触发电脑扬声器（或者蓝牙设备）响铃提醒，期间无需说话、手部动作或物理接触。

## 核心特性
- **无需言语行动**：仅需通过眨眼模式即可操作，无需说话、手部动作或物理接触。
- **轻量资源占用**：可在纯 CPU 环境运行，内存占用低于 500 MB。
- **用户友好**：
    - 支持自定义眨眼模式、提醒音频、音量与持续时间。
    - 同时支持本地摄像头与远程摄像头模式，部署更灵活。
    - 支持一键下载与更新模型文件。
    - 提供日志与调试选项，便于现场使用和算法改进。
