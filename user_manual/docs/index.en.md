# Blink Call User Manual

**Blink Call** is an auxiliary call system designed for ALS (Amyotrophic Lateral Sclerosis, also known as Lou Gehrig's disease) patients. It recognizes user-defined blink patterns from camera input and triggers an alert sound through computer speakers or Bluetooth devices, requiring no speech, hand gestures, or physical contact.

### Core Features
- **Hands-Free Operation**: Operate using only blink patterns, no speech, hand gestures, or physical contact required.
- **Lightweight Resource Usage**: Runs in pure CPU environments with memory consumption below 500 MB.
- **User-Friendly**:
  - Support for customizable blink patterns, alert audio, volume, and duration.
  - Flexible deployment with both local and remote camera modes.
  - One-click model file download and update.
  - Logging and debugging options for monitoring usage and algorithm improvement.
