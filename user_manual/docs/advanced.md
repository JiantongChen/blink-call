# 高级与辅助功能

本页介绍一些不影响日常呼叫主流程的辅助设置。

## 切换语言

操作路径：

设置 -> 常规 -> 语言。

可以在中文和英文之间切换。

## 切换亮色/暗色模式

操作路径：

设置 -> 常规 -> 亮暗模式。

可以根据使用习惯选择浅色或深色界面。这个设置只影响显示效果，不影响呼叫功能。


## 录制当前相机数据

操作路径：

设置 -> 其他 -> 录制当前相机数据。

此功能用于保存当前摄像头画面，通常在开发者或工作人员需要排查识别问题时使用。

日常呼叫不需要开启。

## 调试模式与日志

操作路径：

设置 -> 其他 -> 调试模式。

此功能用于显示或保存软件运行日志，通常在开发者或工作人员需要排查问题时使用。

日常呼叫不需要开启。

## 恢复默认设置

操作路径：

设置 -> 其他 -> 恢复默认设置。

如果设置被改乱，可以使用此功能恢复到软件默认配置。

恢复后，建议重新完成一次测试呼叫。
